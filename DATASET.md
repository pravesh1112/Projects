# Dataset

This project uses the **Admission Chance** dataset containing 400 student
records.

The dataset is loaded directly in the notebook from the YBI Foundation
GitHub repository:

https://github.com/ybifoundation/Dataset/raw/main/Admission%20Chance.csv

## Features

- GRE Score
- TOEFL Score
- University Rating
- SOP
- LOR
- CGPA
- Research

## Target

- Chance of Admit

The notebook also contains a `Serial No` column, which is an identifier and
is not used as a predictive feature.

## Note

Please check the original dataset repository and its licensing/usage terms
before redistributing the raw dataset with this project.
